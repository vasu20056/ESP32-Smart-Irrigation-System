# Firmware

This folder contains the firmware source code for the Smart Irrigation System.

## ESP32 Firmware
`automatic irrigation esp 32.ino`

The main ESP32 firmware handles soil moisture monitoring, automated irrigation control, Wi-Fi connectivity, and the web dashboard.

## Arduino Uno Firmware
`automatic irrigation uno.ino`

An additional Arduino Uno firmware implementation is included in the project repository.

## Setup
1. Install the Arduino IDE and the appropriate board support package.
2. Review the source code and required libraries.
3. Configure your local Wi-Fi credentials before running the ESP32 firmware.
4. Check the wiring and test the system safely before operating the pump.

See the [main project README](../README.md) and [Deployment Guide](../docs/DEPLOYMENT_GUIDE.md) for more information.
